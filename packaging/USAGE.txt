cs-net v5 — 使用说明
====================

这是一个 Windows 上的本地工具：Demo 库 + 3D 回放 + AI 分析。
不需要安装 Python，也不需要命令行。


第一次打开
----------

1. 双击本目录下的 cs-net.exe。
2. 会打开一块控制台窗口，里面是启动信息（和 `python -m app.server` 一样的横幅）：

       cs-net v5 · Demo 库 + 3D 回放
       Demo 库:   http://127.0.0.1:5000/library
       玩家:      http://127.0.0.1:5000/players
       回放页:    http://127.0.0.1:5000/replay
       数据目录:  ...\data
       地图:      ...\maps\optimized_obj_files

   把「Demo 库」那一行的地址复制到浏览器里打开就行。程序**不会自己开浏览器**
   （打包后的 exe 里让别的程序开浏览器并不可靠），也不弹窗口 —— 地址就摆在你
   眼前，爱什么时候开、用哪个浏览器都行。
   窗口要一直留着：它就是服务本身，关掉窗口服务就停了。
3. 库默认是空的。点右上角的「设置」，把存放 .dem 的目录粘进去，
   点「保存」再点「扫描」。
4. 剩下的事它自己干：提取（.dem → .csz）、生成缩略图。
   进度在列表和顶栏的「任务」抽屉里，控制台里也能看到请求日志。

要退出：在那块控制台里按 Ctrl+C，或者直接关掉窗口 —— 服务、后台任务、目录监听
都会停干净。下次还要用就再双击一次。

想要别的形态（可选）：
    cs-net.exe --open     启动后顺便打开浏览器
    cs-net.exe --tray     不占控制台，改成任务栏右下角的托盘图标（右键有菜单）
    cs-net.exe --window   弹一个小窗口，上面有「打开界面 / 复制地址 / 退出」按钮
    cs-net.exe --port 8080   换端口（默认 5000；被占用时会自动换一个）
用这些参数的办法：右键 cs-net.exe → 创建快捷方式 → 在快捷方式的「目标」后面
加上参数。


这个文件夹里都是什么
--------------------

cs-net.exe      程序入口，双击它
_internal\      程序本体（Python 运行时、依赖、网页资源）
                **不要删除、不要改名**，删了程序就打不开了
maps\           地图几何，已经解压好，不用管
models\         两份 AI 权重。只有 "lite" 包是空的：
                第一次打开 AI 面板时，库页面顶上会出现下载横幅，
                点一下就会下载（约 665 MB，可以断点续传）
data\           你的数据：设置、库、提取出来的 .csz、缩略图、日志
                第一次运行会自动创建。整个文件夹拷到别的机器就能带走
build-info.json 版本号和构建信息（反馈问题时请附上）

想换台电脑？把整个文件夹拷走就行，不需要安装，也不写注册表。


常见问题
--------

「Windows 已保护你的电脑」
    这个包没有做代码签名。点「更多信息」→「仍要运行」；
    或者右键 cs-net.exe → 属性 → 勾选「解除锁定」。

解压很慢
    这个包里有几万个小文件，Windows 自带的解压会慢。建议装个 7-Zip 或
    Bandizip 再解压。

双击之后窗口一闪就没了
    说明启动失败 —— 正常时那块控制台会一直留着。失败时程序会停住等一次回车，
    把窗口里的报错和 data\logs\desktop.log 的最后几行发出来就行。

AI 面板打不开 / 一直转圈
    先看 data\logs\desktop.log。
    也可以在命令行里跑一次自检，把最后一行 SELFTEST_JSON 发出来：
        cs-net.exe --packaging-selftest

想手动放权重
    lite 版如果下载不动，把 weights 压缩包解压到 models\ 下，
    目录结构应该是 models\aim\<文件名>.pt 和
    models\spatial_prediction\<文件名>.pt（同名 .yaml 也要在）。

托盘图标看不见 / 想临时看那个小窗口
    双击（不带参数）启动的是控制台模式，本来就没有托盘图标。
    想要托盘：右键 cs-net.exe → 创建快捷方式，在目标后面加 --tray。
    想要那个带按钮的小窗口：加 --window。
    （托盘图标可能被 Windows 折进任务栏的 ^ 里，拖出来固定住就行。）

再双击一次，为什么没有第二个窗口
    已经有一个在跑了。第二个进程只会把在跑的地址打出来然后退出，不会起第二个
    服务抢同一个库。

控制台里报端口被占用 / 地址不是 5000
    5000 被别的程序占了，程序自动换了一个空闲端口 —— 用启动信息里印出来的那个
    地址就对了。想固定端口：--port 8080。
