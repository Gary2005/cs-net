# Runtime dependencies of the packaged app — the ones that end up inside the zip.
#
# This is **not** the dev list (that is the repo-root requirements.txt): training
# only packages (matplotlib / tqdm / pyyaml) are left out, and every version is
# pinned so a release build is reproducible.  Python must be 3.12: every native
# wheel here (demoparser2 / numba / llvmlite / torch) is cp312-only, no abi3.
#
# torch is the CPU build on purpose.  The default Windows wheel is +cu128 (4.4 GB
# of CUDA DLLs, plus a `DLL load failed` risk on machines without the CUDA
# runtime); the app's inference is a few hundred milliseconds on 10 players, so
# the GPU buys nothing and costs ~3.5 GB in the zip.
--extra-index-url https://download.pytorch.org/whl/cpu
