坐标与几何约定（和 tasks/aim.py 的写法一致）：

  • x y z 是脚底；眼位 = z + 64.0938 − 18·crouch，盒子半宽 16 HU、高 72（站）/ 54（蹲，这里用连续的 crouch 近似阶跃）。
  • 角度约定：yaw 0° = +x、90° = +y；pitch 正 = 向下看。还原角度用 atan2(sin, cos)，不会在 ±180° 处跳变。画面左 = yaw 增大（右手方向是 f × up = (sin y, −cos y)），投影用这个符号，别写反。
  • 样本现在是逐帧全场布局：ctx_player (T,10,20) + ctx_player_mask (T,10) + obstruction (T,10,10)，载荷里压成 channel-major 的 players。 取"第 t 帧第 p 个人"就是 players.x[t][p]；A / B 只是 mask 为 1 / 2 的那两行 （载荷另给了单人视图 d.atk / d.tgt）。
  • 死人（mask == 0）没有有效坐标：雷达、玩家表、第一人称画布都按 mask 过滤，表里整行变灰。
  • 遮挡矩阵是逐帧两两射线：0 通 / 1 烟 / 2 墙，有方向；死人的行 / 列恒为 0， 面板里按 mask 画成暗格而不是"通"。
  • 包围盒是纯几何，遮挡另外用 obstruction 标在盒子上 —— 盒子不会因为墙后而消失，只降透明度。
  • since_shot ≥ 99.9 是饱和值（本回合还没开过枪）；blinded 和 defuser 都是玩家私有状态（对手看不到你被闪 / 你有没有钳子）， 做单视角模型时别把对方那两维当可观测输入。
  • HUD 第一项是手里那把枪：图标来自 3D 回放器共享的 CS2 HUD 素材 （visualizer/static/assets/weapon_icons），逐帧跟着 atk_series / tgt_series 变；玩家表里每个人的武器用 players.weapon[t][p] 的全局下标查 weapons.names。图标素材缺失时只显示武器名。
  • 回合时间 = global_feat[t][4] × 200（逐帧），0 点 = 本回合 round_freeze_end（和游戏里右上角倒计时一致），不是窗口起点；它和 seconds 严格同步：global_feat[t][4] × 200 − global_feat[0][4] × 200 = seconds[t]。
