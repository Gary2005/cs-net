基于 Transformer 的 Counter-Strike 2 比赛深度学习分析框架。上传 Demo，一键获取胜率、击杀、死亡、存活、对决胜率五大预测。

Prediction Tasks

五大预测任务

给定一段 CS2 比赛回放，模型能同时输出五种实时预测，覆盖从宏观胜负到微观对枪的完整分析链路。

🏆

Win Rate 胜率预测

当前回合 Team1（按攻防映射）最终获胜的概率

输出: 标量 [0, 1]
💚

Alive 存活预测

每个玩家在本回合结束时仍然存活的概率

输出: 10 个概率值
🎯

Next Kill 下一击杀

哪个玩家最可能拿到下一次击杀

输出: 10+1 类概率分布
💀

Next Death 下一阵亡

哪个玩家最可能成为下一次阵亡者

输出: 10+1 类概率分布
⚔️

Duel 对决胜率

任意 CT-T 玩家对之间的 1v1 胜率矩阵

输出: 5×5 概率矩阵
Web App

功能一览

Windows EXE 开箱即用，一键启动本地 Web 分析面板，支持中文 / English 双语。

回合胜率曲线

带击杀标记的逐 tick 胜率变化曲线，一目了然看到局势转折。

实时 2D 雷达

鼠标悬停时间线同步刷新，在真实地图上画出玩家位置、阵营颜色、存活状态。

逐 Tick 指标面板

四头模型输出完整展开：存活概率、击杀/阵亡分布、5×5 对决胜率矩阵。

高级指标表

全场聚合：平均 kill/death/survive 概率、硬仗/易仗胜率、highlight 率、关键击杀排行。

AI 赛后复盘

接入 OpenAI 兼容 LLM，流式输出 + Markdown 渲染，自动带入攻防上下文降低幻觉。

2D 回放器

一键在新标签页播放 demo，包含烟雾/闪光/手雷弹道，叠加 CS-NET 预测时间线。

MVP / SVP 标记

基于全场贡献值自动评选 MVP 和 SVP。

设置自动记忆

API Key、模型路径、语言等偏好自动存入浏览器本地存储。

Tutorial

使用教程

以下方式二选一：Windows 用户推荐 EXE；开发者可直接运行 Python 源码。

A

Windows EXE 一键启动

下载 cs-net-windows.zip，解压后双击 cs-net.exe。浏览器自动打开 http://127.0.0.1:7860。

模型权重已内置在 EXE 中，无需额外下载。

B

Python 开发者模式

适合需要在源码基础上修改或二次开发的用户。

1

搭建环境

conda create -n cs-net python=3.10
conda activate cs-net
pip install -r requirements.txt
2

下载模型

将预训练模型下载到 ./cs-net-models/（EXE 用户跳过此步）。

python -m scripts.download_model

也可以从 Hugging Face 手动下载。

3

转换 Demo

将 CS2 的 .dem 回放文件解析为结构化 JSON。

python -m data.process_demo \
  -path examples/your_match.dem \
  -interval 0.25 \
  -out examples/your_match.json
4

启动 Web 分析面板

python -m demo_analysis.web_app

打开 http://127.0.0.1:7860，上传 JSON 文件，选择模型目录和设备，点击开始分析。

5

生成 AI 复盘（可选）

填写 OpenAI 兼容的 API Key、模型名和 Base URL，选择语言，点击生成 AI Review 即可获得流式输出的赛后总结。
